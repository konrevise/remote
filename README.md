# konrevise.Remote

эту программу я писал для личных целей, но не чтобы сделать полноценный продкт, которым кто-то всерьез будет пользоваться.
я хотел изучить базовое устройство веба и кибербезопасности, и так появился этот репозиторий.

чтобы сайт работал, нужно взять какой-нибудь ПК на линуксе с оболочкой xfce (ну или просто поменяйте команды в исходниках) и запустить проект через dotnet run или собрать его и запустить получившийся исполняемый файл.

этот сайт может только управлять состоянием ПК - то есть выключить, перезагрузить, заблокировать или отправить в сонный режим.
помню, как я хотел еще прикрутить туда еще одну страницу для просмотра процессов и управлением ими, но что-то пошло не то, и диспетчер задач сделать не вышло...

вроде это все.
